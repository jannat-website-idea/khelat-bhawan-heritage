# Khelat Bhawan — Official Heritage Website Redesign

> **Living Bengali Heritage & Aristocratic Grandeur Since 1845**
> Pathuria Ghata Ghosh Bari • 47, Pathuria Ghata Street, Kolkata – 700006

A luxury, modern heritage web application commemorating over 175+ years of Bengali cultural preservation, sacred devotion, classical Hindustani music, and community stewardship.

---

## 🏛️ Heritage Highlights
- **Establishment**: Founded in **1845** by visionary Bengali businessman and arts patron **Babu Khelat Ghosh**.
- **Divine Sanctity**: Blessed in **1881** by the historic visit of **Sri Ramakrishna Paramhansa**.
- **Sacred Traditions**: Continuous annual **Durga Puja** celebrated uninterrupted since **1855** (170+ continuous years) and **Jagadhatri Puja**.
- **Three Active Cultural Trusts**:
  1. *Lakshmi Narayan Gopal Radha Krishna Jew Trust* (Est. 1855) — Devotional & Spiritual Preservation.
  2. *Khelat Ghosh Memorial Trust* (Est. 1950s) — Classical Indian Music Patronage & Artist Welfare.
  3. *Artist Nectar Council of Culture* (Est. 2000+) — Performing Arts, Children's Education & Healthcare Awareness.

---

## 🎨 Visual Identity & Design System
- **Color Palette**: Signature Royal Rose Gold (`#B87D65`), Deep Burgundy / Wine (`#4A121A`), Warm Ivory & Aged Parchment (`#FAF8F5`), Charcoal (`#1A1817`).
- **Typography**: Editorial Serifs (*Playfair Display*, *Cormorant Garamond*), Modern Sans-Serif (*Plus Jakarta Sans*), Bengali Serifs (*Noto Serif Bengali*, *Hind Siliguri*).
- **Bengali Cultural Motifs**: Custom SVG Alpana dividers and traditional floral ornaments.
- **Bilingual Interface**: Full instant **English ↔ বাংলা** language toggle.

---

## 💻 Tech Stack
- **Framework**: React 18, Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Deployment**: GitHub Pages (Automated CI/CD via GitHub Actions)

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/jannat-website-idea/khelat-bhawan-heritage.git

# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
